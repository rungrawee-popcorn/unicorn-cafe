# Unicorn Cafe 🦄

A modern cafe ordering web application that allows customers to browse menu items, add products to cart, select payment methods, and complete orders.

## Features

- Browse menu items by category
- View food and beverage menus
- Add items to cart
- Increase / decrease item quantity
- Remove items from cart
- Checkout system
- Select payment method
  - Cash
  - Payment via Application
- Order confirmation page
- Generate mock order ID
- Display order summary
- Clear cart after successful order

## Menu Categories

- Savory Dishes
- Beverages
- Desserts
- Light Bites
- Soups

## Tech Stack

Frontend:

- React
- TypeScript
- Vite
- Material UI (MUI)
- React Router

## Installation

Clone the repository:

```bash
git clone https://github.com/rungrawee-popcorn/unicorn-cafe
```

Navigate to the project folder:

```bash
cd unicorn-cafe
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

The application will run at:

```bash
http://localhost:5173
```

## Application Pages

### Menu

- Display menu items by category
- Browse available food and beverages

### Cart

- Review selected items
- Update item quantity
- Remove items from cart
- View total price

### Checkout

- Review order details
- Select payment method
- Confirm order

### Order Success

- Display order confirmation
- Generate order ID
- Show order date and payment method
- Clear cart after order completion
